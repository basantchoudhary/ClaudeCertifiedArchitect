1 The exam in one minute

60 questions in 120 minutes. Multiple choice, plus some “pick two”. Each question says how many to select.
4 scenarios drawn from a bank of 6. Each scenario is a system you are helping to design or fix.
Pass mark: 720 on a scale of 100–1,000. Results show your percent correct by domain.
The questions are plain. The hard part is the options: they're all real practices, and only one fits best.

Most wrong answers are good practices used in the wrong place. Three families cover most of them:

Right idea, wrong layer. A prompt where a rule needs code, or code where a prompt is enough.
Fixing the symptom. A retry, a bigger limit or a log, when the cause is somewhere else.
Right content, wrong home. A personal file for a team rule, or an always-loaded file for an occasional task.

2 Your study path

  1. Learn the five domains, biggest first (section 4). Each has lessons, diagrams and a quiz bank.
  2. Read the mind map for each scenario (section 5). Print it, cover the Fix column, and fill it in from memory.
  3. Train on the traps (section 6). Each trap page has a simulator that shows each option playing out, then exam-style practice.
  4. Sit Mock #7, plain style under the 120-minute timer. It reads like the real exam.
  5. Review every miss with “Think it through”. Note the trap name on the option you picked. If the same trap keeps catching you, go back to its trap page.
  6. Keep practising with Mocks #6, #5 and #4, and the per-domain practice sets.
