CCA-F: start here

Everything for the Claude Certified Architect – Foundations exam, in the order to use it. The exam tests judgement: every question gives you several sensible options, and you pick the one that fits the situation best.

The exam at a glance

60 questions in 120 minutes. Multiple choice, plus some “pick two”; each question says how many to select.
4 scenarios drawn from a bank of 6. Each scenario is a system you are helping to design or fix.
Pass mark: 720 on a scale of 100–1,000. Results show your percent correct by domain.
The questions are plain. The hard part is the options: all of them are real practices, and only one fits best.

Your path

  1. Learn the five domains, biggest first. Each domain has lessons, diagrams and a quiz bank (table below).
  2. Train on the traps. After each domain, open its traps in the Trap gym: a simulator shows each option playing out, then exam-style practice.
  3. Sit Mock #7, plain style under the 120-minute timer. It reads like the real exam.
  4. Review every miss with “Think it through”. Note the trap name on the option you picked; if the same trap keeps catching you, go back to its Trap gym page.
  5. Stretch with Mock #6, then Mocks #5 plain (original) and #4 plain (original).

The traps

Most wrong answers on this exam are good practices used in the wrong place. Three families cover most of them:

Right idea, wrong layer. A prompt where a rule needs code, or code where a prompt is enough.
Fixing the symptom. A retry, a bigger limit or a log, when the cause is somewhere else.
Right content, wrong home. A personal file for a team rule, an always-loaded file for an occasional task.
