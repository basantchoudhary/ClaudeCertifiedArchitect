How to read it. Each scenario tests 2 or 3 domains, never all 5. Domain 4 sits in only two scenarios (5 and 6), and Domain 5 sits in four. Because you get 4 of the 6 scenarios, every domain has at least one of its scenarios on your paper, so study all five.

The five mind-map pages

  • Support agent: when the loop stops, prompt or hook, cleaning results, escalation, several matches, exact facts
  • Multi-agent research: coverage gaps, subagent context, fixed or adaptive, tools per agent, failures, sources
  • MCP: config home, tool or resource, wrong tool picked, failed tool returns
  • Claude Code: instruction home, plan or do, iterating, CI, long sessions, built-in tools
  • Structured extraction: JSON that parses, schemas that don't invent, retries, consistency, batch, human review
