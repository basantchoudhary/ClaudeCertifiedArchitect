# Beat sheet: "Examples, tests or interview?" (about 8–10 minutes)

Not a script. Glance at the point, then say it in your own words while showing the page.
Record one beat per take, and pause 2 seconds before restarting a sentence; the fillers get cut in editing.

## 1. The hook (30 s)
- Show the page title.
- Say: Claude's work keeps coming back not quite right. Every option is a real way to iterate: more words, examples, tests, questions, one message or several.
- The trap: a good technique for the wrong gap. Name what's missing first.

## 2. Hairdresser and tailor (1 min)
- Three boxes. A photo beats a paragraph about a haircut: that's examples.
- The tailor fixes one sleeve and ruins the other, so you chalk every measurement first: tests first.
- You don't know what you want for the wedding, so the tailor asks: the interview pattern.
- Then the extra question for several problems: do the fixes affect each other?

## 3. The diagram (1 min)
- Left column, what's missing. Right column, the technique. Read the four rows across.
- Point at the fork: several problems split into one message (they interact) or one at a time (independent).
- Point at the dashed prose box at the bottom: the fallback. It often works, it's rarely the best answer.

## 4. The one question (1 min)
- Butter box: "Doesn't understand the transformation, fixes keep breaking cases, or nobody has defined what's wanted?"
- Read the four word lists quickly: "rewritten the spec four times", "each fix breaks another case", "several reasonable readings", "the problems interact".

## 5. Simulator (3 min). The heart of the video
- Explain the squares once: green right, pale pink wrong, dark pink with an outline = was right, now broken.
- Addresses + prose: 4 rounds, 40 min, Only usually works. Then addresses + examples: 2 rounds, 12 min, Best fit. "Three records said what four rewrites couldn't."
- Fare rounding + one message per issue: 6 rounds, 2 breaks, Delays the problem. "Whack-a-mole, checked by hand."
- Fare rounding + tests first: 3 rounds, 19 min. Point at round 2: the rupee case broke, and the suite caught it in seconds. Best fit.
- Reminders + tests first: Wrong order, 62 min, the slowest. "Tests lock in the guesses." Then reminders + interview: 1 round of code, 29 min, Best fit.
- The twist: checkout bugs + one message per issue: Fixes collide, 6 breaks. Then unrelated bugs + one message per issue: Best fit, 15 min. "Same choice, opposite verdicts. The question is whether the problems interact."
- Say once: the rounds and minutes are illustrative; the shape is what the exam guide says.

## 6. The four traps table (1 min)
- Read the four wrong options, and match each to a run you just did: addresses + prose, fare rounding + one per issue, reminders + prose, checkout bugs + one per issue.
- Point at the line under the table: plan mode vs direct execution is a different page.

## 7. Practice question 1, live (2 min)
- Read the stem. Point at "rewritten a prose spec four times" (examples) and "want later changes checked against those answers" (tests).
- It's a pick-TWO. Rule out the interview (the engineer already has a firm answer) and more prose (more of the same).
- Click A, open "Think it through", show the mind map.
- Leave question 2 (the interview) and question 3 (one message or several) for the viewer: "pause and try them".

## 8. Close (20 s)
- Rule to remember: unclear transformation, show examples; fixes keep breaking things, write tests first; unclear request, let Claude ask first.
- Point back to the Trap gym page for the next trap.
