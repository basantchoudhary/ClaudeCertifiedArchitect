Mock 7, rewritten in plain style

Five questions, one per domain, rewritten to read like the real exam: a short problem, then the question. One answer is clearly best if you know the rule. Every wrong option is a real practice that is wrong here for a reason you can name.

How to judge these. Answer each one first. Then open Before to compare it with the Mock 7 version. Ask yourself two things:
  1. Did the question read as easily as the real exam?
  2. Was the winner clear once you knew the rule, while the wrong options still tempted you?
What changed from Mock 7
  • The whole situation in plain words: what happens today, what goes wrong, then the question. About the same length as Mock 7, but simpler sentences.
  • No planted clue sentences such as “The tool results are short” or “Missing it in some chats is acceptable”. The deciding fact is part of the problem.
  • Wrong options are labelled with their trap (overbuilt, only usually works, wrong action, and so on) instead of a runner-up that “wins if one fact changed”.
  • Kept: “Explain simply” and “Think it through” on every question.
