What this is

A second exam-grade paper, built to the same four rules as Mock #4:

  • The stem carries real system state and numbers — what was already tried, and what it cost.
  • All four options are things a competent architect might actually do. Usually two are genuinely good ideas.
  • The discriminator sits in the qualifier — first step, guarantees, root cause, least added complexity. Read it before you read the options.
  • Every option carries its own rationale on reveal, so a wrong pick teaches you where the boundary actually is.

Nothing here repeats Mock #4. Every stem, every correct answer and every distractor is new — checked programmatically, not by eye. The six scenarios are the same official systems, but each brief carries different system state, so no item can be answered from memory of the previous paper.

Sit this one after Mock #4, ideally a day or more later. Because the traps repeat but the surfaces do not, the gap between your two scores is the useful number — it tells you whether you learned the principle or just the previous paper's answers.
