The least autonomy that works

D1 · Solution Design & ArchitectureGuide lines 1.3, 1.4

At a glance: Choose the simplest pattern that solves the problem: one call, then a fixed workflow, then a single agent, and several agents only when the work splits into independent parts worth the cost.

There is a ladder of patterns. An augmented LLM is one Claude call, perhaps with retrieval or a tool. A workflow is several calls in an order your code decides, so it is predictable, testable and cheap. An agent lets the model decide the next step in a loop, which is flexible but costlier and harder to predict. A multi-agent system adds a coordinator and subagents, each with its own fresh context, and uses many more tokens again.

Each step up the ladder buys flexibility and pays for it in cost, latency and predictability. So climb only as far as the problem needs. If the steps are the same every time, code can run them. If the next step depends on what was just found, an agent earns its place. If the work splits into several independent, open-ended threads, valuable enough to justify the tokens, a coordinator with parallel subagents fits.

The trap is that agents sound modern and capable. On the exam, the deciding fact is usually whether the steps are known in advance.

Change one fact

An accounting firm wants Claude to process expense claims. Every claim goes through the same steps in the same order: read the receipt, extract the amount and category, check them against the expense policy, and write a short note for the approver. An engineer proposes a manager agent that hands each step to its own specialist agent. What should the architect choose?

    Words in the stem that signal this trap

    • “every item goes through the same steps” (a workflow)
    • “the next step depends on what it finds” (an agent)
    • “independent parts”, “separate sources”, “in parallel” and high value (multi-agent)
    • a single prompt that already passes the evaluation
    • an engineer who proposes agents because they are more flexible
    Rule to remember: Use the least autonomy that solves the problem. Known steps belong in a workflow; an agent is for paths that cannot be known in advance; several agents are for independent, valuable threads.

    Practice

    Practice 5.1 · Choose one.

    A city's public-services line receives text messages that are pothole reports, noise complaints or missed bin collections. Each type goes to a different department with its own form and wording. An engineer proposes an agent that reads each message and decides what to do with it. Which pattern fits best?

    1. An agent that decides for each message which tools to call and in which order.
    2. A coordinator agent with one subagent per department, each with its own tools.
    3. A router that classifies each message and passes it to a prompt for that form.
    4. One general prompt that handles all three types and fills whichever form fits.
    Show answer

    Answer: C. The deciding fact: messages fall into a few distinct types, each handled differently. Routing gives each type its own tuned prompt, with steps known in advance.

    • A ❌ Works when the path is unknown, but here the path is fixed once the type is known.
    • B ❌ Works for independent, open-ended threads, but each message is one short task.
    • C ✅ A router that classifies each message and passes it to a prompt for that form.
    • D ❌ Works for similar inputs, but three different forms are better served by tuned prompts.
    Practice 5.2 · Choose one.

    A drug company's strategy team wants a weekly briefing on competitors from four separate sources: trial registries, regulatory notices, journals and patent filings. Each source needs several rounds of searching, where the next search depends on what turned up. The four threads do not depend on each other, and the briefing is high value. What design fits?

    1. A coordinator that hands each source to its own subagent and merges results.
    2. A fixed workflow that runs one set query per source and then writes the briefing.
    3. A single agent that searches the four sources one after another in one context.
    4. One Claude call with all four sources' search results pasted into the prompt.
    Show answer

    Answer: A. The deciding facts: four independent, open-ended threads, and a high-value result. Parallel subagents keep each thread in its own context, and the value justifies the extra tokens.

    • A ✅ A coordinator that hands each source to its own subagent and merges results.
    • B ❌ Works when one query per source is enough, but here each search depends on the last.
    • C ❌ Works for linked steps, but four unrelated threads crowd one context and run slowly.
    • D ❌ Works for a one-step task, but a single call cannot run follow-up searches.
    Practice 5.3 · Choose two.

    A bank's business-onboarding workflow checks applications in five fixed steps and meets its targets on most cases. The team is considering replacing it with an agent. Which two findings would justify that change?

    1. The workflow's prompts have grown long, and the team finds them hard to maintain.
    2. Many applications need different checks depending on what earlier checks find.
    3. A newer model has been released that is better at choosing which tool to call.
    4. On those varied cases, the workflow fails the evaluation and an agent prototype passes.
    5. Volume will double next year, and the cost per application is already over plan.
    Show answer

    Answer: B and D. The deciding facts: the path now depends on findings, and evidence shows the simpler pattern falls short where an agent succeeds. Autonomy is added when evaluation shows it is needed.

    • A ❌ Works as a reason to tidy prompts into modules, not to change the pattern.
    • B ✅ Many applications need different checks depending on what earlier checks find.
    • C ❌ Works as a reason to test the new model, but it does not change what the task needs.
    • D ✅ On those varied cases, the workflow fails the evaluation and an agent prototype passes.
    • E ❌ Works as a reason to cut cost, but an agent usually costs more per case, not less.
